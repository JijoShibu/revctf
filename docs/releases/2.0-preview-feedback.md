# Draft preview feedback request

For posting on GitHub after the preview is published and posting is authorized.

RevCTF 2.0 has a preview available for testing. This update concentrates on incomplete
results, memory limits, and stopping challenge programs when a scan is interrupted.

If you can test on Kali with 4 GB allocated, please try a small challenge with a known
answer and tell us what happened. We are interested in installation problems, incorrect
candidates, missing expected results, and scans that fail to stop cleanly.

Please include:

- The output of `revctf --version`, your Kali version, and RAM allocation.
- The command you ran, file type, and any non-default options.
- What you expected, what RevCTF reported, and how you know the correct answer.
- A short relevant output excerpt, with passwords, tokens and private information removed.

Use the repository's bug-report form. Share challenge files only when you have permission.
The preview notes explain current limitations and how to return to your previous checkout.

Stable 2.0 will follow at least seven days of preview availability, an independent Kali
test report, and resolution of release-blocking issues. Thank you for helping test it.
